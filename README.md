**Проект "Моя родина - моя гордость: Виртуальное путешествие по наследию Курской области"**

Данный проект создан для продвижения Курской области в интернете и с целью повышения квалификации автора.

**Деплой**:
*Статика - timeweb хостинг.*

**Управление проектом**
# Frontend
    npm run dev # разработка
    npm run build # сборка


*Технологии разработки*

1. Frontend
    Разработка ориентирована на создание интуитивно понятного и простого интерфейса (UI) и продуманного пользовательского опыта (UX) на базе библиотеки React.js и фреймворка Next.js. Функционал включает: адаптивную вёрстку (desktop/tablet/mobile), бургер-меню, карточки с описанием, интерактивные карты и форму обратной связи. Особое внимание уделено accessibility (доступности): предусмотрены настройки размера шрифта, переключение между темами и режимом для слабовидящих, а также семантическая вёрстка. Проект кроссбраузерен и оптимизирован для всех типов устройств.

    Сайт разбит на 10 страниц:
    1. Главная
    2. Культура
    3. История
    4. Экология
    5. Экономика
    6. Туризм
    7. Отзывы
    8. Политика конфиденциальности
    9. Источники
    10. Not-found (404)

    Языки разработки:
    * HTML5
    * CSS
    * JavaScript

2. Дальнейшая поддержка и анализ аудитории
    Для отслеживания посещаемости, поведения пользователей и технического состояния сайта подключены системы веб-аналитики: Яндекс.Метрика и Google Analytics. Проект зарегистрирован в Яндекс.Вебмастер и Google Search Console для управления индексацией сайта в поисковых системах.
