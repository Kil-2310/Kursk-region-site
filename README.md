# Моя родина - моя гордость: Виртуальное путешествие по наследию Курской области

## О проекте

Данный проект создан для комплексного продвижения Курской области в интернете. Он представляет регион как привлекательное туристическое, культурное и деловое направление, собирая в едином пространстве ключевые сведения об истории, природе, экономике и традициях края. Цель проекта — повысить узнаваемость области среди широкой аудитории, вдохновить на путешествия и сформировать положительный имидж региона. Проект состоит из 10 страниц:

    1. Главная
    2. Культура
    3. История
    4. Экология
    5. Экономика
    6. Туризм
    7. Отзывы
    8. Политика конфиденциальности
    9. Источники
    10. Not-found (404)

## Технологический стек

    * HTML5 — семантическая разметка и структура страниц.
    * Python - высокоуровневый язык программирования.
    * CSS — стилизация и адаптивная верстка.
    * SCSS — расширенный синтаксис CSS с переменными, миксинами и вложенностью.
    * JavaScript — логика взаимодействия, асинхронные запросы и манипуляции с DOM.
    * React.js — компонентный подход, управление состоянием и построение интерфейсов.
    * Next.js — серверный рендеринг, маршрутизация и оптимизация производительности.

## Инструкция по запуску и управлению проекта

### Установка ПО и настройка проекта

Перед сборкой проекта необходимо установить пакетный менеджер npm и node.js, с официального сайта. После установите все зависимости проекта командой: npm i

Для функционирования почтовой службы необходима регистрация на Web3Forms. Однако данная функция не является критической — при отсутствии регистрации проект сохранит работоспособность, а файл .env может оставаться незаполненным.

Создать и заполнить .env файл пр примеру ниже:

    NEXT_PUBLIC_ENDPOINT_URL=https://api.web3forms.com/submit
    NEXT_PUBLIC_SECRET_FORM_KEY='Ваш ключ с сайта Web3Forms'

    NEXT_PUBLIC_YANDEX_METRICA_ID=


### Запуск и остановка проекта

``` bash
npm run dev
Ctrl + C
```
